
2. Enter name, email, password
3. Click "Sign Up"

## Troubleshooting

### Sign up not working?
1. Make sure DATABASE_URL is set
2. Restart dev server: `pnpm dev`
3. Check browser console (F12) for errors
4. Try different email address

### 3D Orb not showing?
1. Check if WebGL is enabled in browser
2. Refresh page
3. Try different browser

### Voice not working?
1. Allow microphone permissions
2. Check browser supports Web Speech API
3. Select language in Settings
